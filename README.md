# Garden Irrigation Firmware

Signed firmware releases for the Garden Irrigation XIAO ESP32-C6 controller.

For the first USB flash, use the release asset ending in `full-0x0.bin` at offset `0x0`. Existing provisioned controllers receive signed OTA updates through the Garden Irrigation Home Assistant integration.

Release manifests and images are generated by CI from the private source repository. Customer Wi-Fi and MQTT credentials are not embedded in public images.
